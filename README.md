# Power BI Assignment 2 - DAX, Data Visualization

## 📊 Project Overview

This project is based on **E-Commerce Sales Analysis** using Microsoft Power BI.  
The assignment focuses on using **DAX (Data Analysis Expressions)**, data modeling, and different Power BI visualizations to analyze sales, profit, targets, orders, and geographical performance.

## 🛠️ Tools Used

- Microsoft Power BI
- DAX
- Power Query
- CSV Data Files

## 📂 Dataset

The project uses the following datasets:

- List of Orders
- Order Details
- Sales Target

## 📌 DAX Concepts Covered

### Calculated Columns
- Category Type
- Revenue per Order
- Sales Category

### Calculated Measures
- Order Count
- Average Profit in Delhi
- YTD Sales

## 📈 Data Visualizations

The dashboard includes:

1. Sales Target Achievement by Category
2. Max Profit Margin by Sub-Category
3. Monthly Sales Trend
4. Profit vs Quantity by Sub-Category
5. Total Sales Amount and Target Cards
6. Sales Performance Matrix
7. Geographic Sales Analysis
8. Sales Distribution by Sub-Category
9. Order Count Analysis by State

## 🎯 Objective

The main objective of this assignment is to understand how **DAX calculations and Power BI visualizations** can be used to transform e-commerce sales data into meaningful business insights.
